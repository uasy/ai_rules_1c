## 4. Портировать preview-слой на Python

**Приоритет: средний** (правило есть, выполнить его на Linux нечем).

- `_common/Invoke-1CEdit.ps1` (463 строки) и `_common/MetadataAddress.ps1` (239 строк) пришли
  с апстримом и **не портированы** (`.py`-пары нет). Вместе с ними на Linux недоступны логическая
  адресация, unified diff и preview, а также чтение `EXPORT_PATH` из `.dev.env` — этот ключ
  читают только они.
- При этом `AGENTS.md:116` (always-on) требует «Preview the diff first (`_common/Invoke-1CEdit.ps1`)»
  без оговорки про рантайм, а `SKILL.md:54` говорит, что враппер «wraps any tool of this skill».

**Внешних зависимостей нет — портируется на stdlib.** Проверено по коду:

- `MetadataAddress.ps1` — только `System.IO.Path` (4 вызова): строки, пути и таблица видов
  метаданных. Переносится почти построчно на `os.path` / `pathlib` и словарь.
- `Invoke-1CEdit.ps1` — `git` как внешний процесс (14 вызовов), `System.Array` / `ArrayList`
  (→ списки) и AST-парсер PowerShell. Diff не своя реализация, а `git diff --no-index` —
  сознательно, чтобы не держать вторую реализацию в синхроне; на Python работает так же.
- На стороне Python нужны только `subprocess`, `shutil`, `os` / `pathlib`, `sys`, `ast`.
  Требование рантайма (Python 3.8+ и `lxml`) не вырастет.

**Единственное место, требующее замены, а не перевода:** `Get-ScriptParameters` читает param-блок
целевого `.ps1` через `System.Management.Automation.Language.Parser`, чтобы понять, куда подставить
разрешённый путь и есть ли у инструмента родной `-DryRun`. Python-версия должна интроспектировать
`.py` с их argparse. Импортировать модуль нельзя — порты парсят аргументы на верхнем уровне,
импорт просто выполнит скрипт; правильный аналог — модуль `ast` из stdlib, разбор вызовов
`add_argument`. Та же техника, что в оригинале (свой AST-парсер своего языка), парсер уже встроен.

**Порядок работ:**

1. Закрыть пункт 1 (гейт в `remove-template.py`). Иначе Python-обёртка при интроспекции не найдёт
   у него `-DryRun`, возьмёт бэкенд отката и будет прикрывать собой инструмент, который сам
   удаляет без подтверждения.
2. `MetadataAddress.py` — самостоятельная и сразу полезная часть (логическая адресация + чтение
   `EXPORT_PATH`).
3. `Invoke-1CEdit.py` поверх неё. Оба бэкенда отката переносятся без изменений: git тот же,
   отказ стартовать на грязном дереве — `git status --porcelain`.
4. Кейсы в `tools/tests/python-ports-regression.py`; в CI Linux-джоб (`--python-only`) уже есть.

**Оговорка про границы:** обёртка сможет оборачивать только портированные инструменты, поэтому
для `web-ops` и прочего непортированного preview на Linux всё равно не появится. Формулировки
в `AGENTS.md` / `SKILL.md` придётся уточнить в любом случае — но уже про остаток, а не про
весь preview-слой.
